## IF DISPUTES NOT RESOLVED: ESCALATION OPTIONS

### **OPTION 1: FILE CFPB COMPLAINT (Free)**

**What:** Consumer Financial Protection Bureau complaint  
**When:** If CRA/furnishers don't resolve by [ESCALATION_DATE]  
**How:** Go to **www.consumerfinance.gov/complaint**

**What to report:**
- [CRA_NAME]
- Furnisher names: [LIST]
- Dispute reference numbers
- Violations not resolved
- Copy of dispute letters + proof of mailing

**Timeline:** CFPB investigates and can impose penalties on CRA/furnishers

---

### **OPTION 2: CONTACT CONSUMER ATTORNEY**

**When:** If violations are egregious and CFPB doesn't resolve  
**Cost:** Many consumer attorneys work on contingency (no upfront fee)  
**What they can do:**
- File FCRA lawsuit against [CRA_NAME]/furnishers
- Seek statutory damages ($100-$1,000 per willful violation)
- Seek actual damages (credit denial, higher rates, emotional distress)
- Seek punitive damages in egregious cases
- Recover attorney fees from defendants

**Potential recovery:** $1,000-$100,000+ depending on violations

**Statute of Limitations:** 2 years from discovery of violation; 5 years from violation

## FINAL REMINDERS

**DO:**
- ✓ Mail all packages via CERTIFIED MAIL with RETURN RECEIPT
- ✓ Keep all receipts and return cards
- ✓ Keep organized records of everything
- ✓ Be professional if furnishers contact you
- ✓ Document all phone calls/emails
- ✓ Wait 30 days for investigations to complete
- ✓ Check updated report after [DEADLINE_DATE]
- ✓ File CFPB complaint if violations persist
- ✓ Take screenshots of online disputes for documentation
- ✓ Send certified mail from USPS counter (not drop box)

**DON'T:**
- ✗ Mail letters via regular mail (no proof of delivery)
- ✗ File multiple disputes on same accounts in short timeframe (frivolous dispute)
- ✗ Contact furnishers/CRA repeatedly (appears harassing)
- ✗ Accept verbal responses without written follow-up
- ✗ Assume disputes are resolved without seeing report changes
- ✗ Delay filing CFPB complaint if needed (3-year statute of limitations)
- ✗ Sign anything from furnishers/CRA without reviewing carefully
- ✗ Pay any fees to file disputes (all filing is FREE)
